用 Skill 连接工作台

下载并安装 Skill，让 Codex 调用内置采集脚本。运行环境随工作台提供，无需另装 Python。

解压后将 shopdesk-operator 文件夹放入 ~/.agents/skills/，在 Codex 中输入 $shopdesk-operator 更新全部店铺的经营数据。未识别时重启 Codex。

仅支持本机工作台。Skill 不包含你的店铺数据或登录凭证。

也可以通过 MCP 连接

  1. 保持工作台运行，在 Codex 新开任务加载 shopdesk MCP。
  2. 复制下方指令发送给 Codex。若提示找不到工具，重启 Codex 后再试。
  3. 需要重新登录时，在店铺 Tab 中扫码，再让 Codex 继续。
