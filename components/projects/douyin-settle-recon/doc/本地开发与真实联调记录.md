## 真实店铺验证

店铺：兹伊翰官方旗舰店，抖店平台ID `87755028`，shopdesk UUID `a18b857a-88b9-406d-9e51-62b9a040098b`，账期2026年9月。云端统一shop_id尚未配置。

| 数据     | 实际结果                                                        |
| ------ | ----------------------------------------------------------- |
| 资金账单   | 52,198笔，下载笔数与官方月汇总一致                                        |
| 结算账单   | 40,923笔交易；另有1行官方字段说明，原样保留并标记column_note，不参与计算               |
| 基础保证金  | 下载2笔完整历史流水，本月1笔                                             |
| 体验保证金  | 下载1,929笔完整历史流水，本月10笔                                        |
| 涉税账单   | 枚举5个主体，3个主体下载成功，2个主体经官方查询确认本月无数据                            |
| 管家账户   | 账户中心提示“需要实名认证后访问”，记录needs_real_name_verification，尚未完成真实采集验证 |
| 本月加工明细 | 52,209行，含资金及两类保证金                                           |
| 输出     | 16张结构化数据表、12张截图证据、Excel与gzip                                |

保证金采用官方页面的无日期筛选导出，清单明确标记 `export_scope=all_history`；计算层严格按操作时间筛选目标月份，其他月份仅保留在原始表中，不混入本月合计。涉税查询核实实际member_id及月份；历史报表按报表ID、类型、店铺、主体及账期验证，签名下载链接留在shopdesk内部。

本次工作台扩展从当前已部署app.asar制作增量补丁，增加截图、受控下载及探索会话清理能力；保留安装备份，未运行工作台源码目录的整体部署脚本。支持 `--resume` 复用已成功的账单及主体结果，避免重试时重复下载。
